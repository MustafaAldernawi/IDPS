02 / HOW IT WORKS

كيف نحول البيانات إلى قرار تشغيلي؟

من المستهدف والخام إلى الإنتاج الحقيقي، ثم التحليل وإعادة التنبؤ عند التوقفات. النظام داعم للقرار، ولا يرسل أي أوامر تحكم صناعي.

دورة العمل الأساسية

  1. التخطيط: مستهدفات شهرية وتوقفات معروفة بإصدار معتمد.
  2. الإنتاج: إدخال الخام وإنتاج المنتجات، الورديات، حالة الوحدات والتوقفات.
  3. هندسة العمليات: Yield وActual/Target والطاقة والفواقد والكيماويات.
  4. AI: بعد جاهزية البيانات — توقع يومي وتجميعه لنهاية الشهر.
  5. إدارة التشغيل: تحليل المخاطر واتخاذ القرار باستخدام تنبيه وتقرير موثق.
التوقعات لها as_of، نسخة نموذج ومصدر. البيانات التجريبية موسومة بوضوح.

سيناريو التوقف المفاجئ

  1. الوحدة يحدث لها Trip غير مخطط عند وقت مسجل.
  2. يُسجل الحدث بأثر تدقيقي؛ يتم تشغيل Reforecast في Queue.
  3. إذا ETA مجهول، تُنشأ سيناريوهات واضحة بفرضيات معتمدة.
  4. يُحفظ Forecast السابق والجديد منفصلين للمقارنة.
  5. بعد تحديث ETA أو Restart يصدر توقع جديد وتُحسب المدة الفعلية.
التغير بين التوقعين ليس قياس خسارة إنتاج سببية مؤكدة؛ هو اختلاف تقدير النموذج.
