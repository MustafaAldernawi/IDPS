# Feature execution specifications

Each folder is intentionally implementable in isolation after dependencies are met: `spec.md` defines the scope, `plan.md` the sequence, and `tasks.md` actionable acceptance.

- `001-platform-foundation` — Platform, Security and Governance, phase P1, 10 tasks, FR-001–008, FR-052–056
- `002-data-ingestion` — Historical Source Ingestion and Data Quality, phase P2, 10 tasks, FR-010–018, FR-052
- `005-planning-quality` — Planning, Target Versions and Optional Quality, phase P2-P4, 10 tasks, FR-009, FR-017, FR-020, FR-032
- `003-production-and-events` — Production Records, Unit States, Trips and Restart, phase P3, 12 tasks, FR-013–016, FR-019–027
- `004-engineering-kpis` — Process Engineering Analytics and Reports, phase P4, 12 tasks, FR-028–036
- `006-ai-training-pipeline` — Dataset Readiness, Baselines and Model Training, phase P5-P6, 15 tasks, FR-037–043, FR-046–047
- `007-event-aware-forecast` — Dynamic Reforecast and Event Impact, phase P7, 10 tasks, FR-044–045, FR-027
- `008-mlops-governance` — Retraining, Monitoring and Model Governance, phase P8, 10 tasks, FR-048–051
- `009-ui-reports-and-release` — User Interface, Reporting, UAT and Release, phase P9, 16 tasks, FR-027, FR-033–036, FR-051–056
